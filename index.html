Como os dados se conectam

  1. Programação (SIGEO): cada linha é um serviço de um projeto numa data, com status, tipo de intervenção, contratada e o(s) código(s) de equipamento.
  2. Equipamento (Buscapé): o código do equipamento da programação é procurado na base Buscapé, que informa circuito, latitude e longitude.
  3. Link de localização: com a latitude e a longitude do equipamento, cada projeto recebe um link para abrir no Google Maps ou no Waze.

Precisão da localização. Exata: o código do equipamento existe na base. Inferida: o código estava escrito em outro formato (por exemplo, ET-004443) e só um equipamento da base combina com ele. Circuito (aprox.): o código é de um disjuntor de alimentador (DJ…) e o ponto mostrado é o centro dos equipamentos do circuito. Sem localização: o código não foi encontrado; o projeto aparece nas pendências.

Fontes e critérios

  • Planilha SIGEO original (programação de 31/10/2026).
  • Base Buscapé (CSV) – coordenadas dos equipamentos, base de 12/06/2026.
  • Datas exibidas no padrão brasileiro (dd/mm/aaaa).
  • Importações feitas aqui ficam apenas no seu navegador e não atualizam o site publicado.
